# 浏览器验收

使用 Playwright CLI 的独立会话验收本地 Visual Radar。验收脚本只访问本机测试服务，不加载个人浏览器会话、不填写真实管理密钥，也不调用发送接口。

## 页面交互验收

先启动构建预览：

```bash
pnpm build:pages
pnpm exec vite preview --host 127.0.0.1 --port 3210 --strictPort --base /visual-radar/
```

再运行 Playwright CLI：

```bash
mkdir -p output/playwright
npx --yes --package @playwright/cli playwright-cli install-browser firefox
npx --yes --package @playwright/cli playwright-cli -s=visual-radar-qa open http://127.0.0.1:3210/visual-radar/ --browser firefox
npx --yes --package @playwright/cli playwright-cli -s=visual-radar-qa run-code --filename scripts/browser-smoke.js
```

脚本覆盖搜索与月份筛选、备注关闭保护、收藏与刷新恢复、返回搜索结果、Markdown 导出、390px 手机无横向溢出、底部导航、全图弹窗 Escape 关闭和键盘跳转。截图和导出文件只写入被忽略的 `output/playwright/`。

## 来源健康面板验收

本地开发前端默认代理到后端 3099；需要测试 API 状态时，可以用 Playwright route mock，不要使用真实管理密钥：

```bash
# 在独立终端保持该前端运行（不需要真实后端）
pnpm exec vite --host 127.0.0.1 --port 3211 --strictPort
# 回到测试终端运行
npx --yes --package @playwright/cli playwright-cli -s=visual-radar-qa run-code --filename scripts/browser-health-smoke.js
```

脚本验证：未输入密钥时按钮禁用、401 可见、成功响应展示失败来源和新加坡时间、来源筛选、手机宽度，以及没有产生 POST 或发送请求。

如果 Chrome 在本机启动崩溃，使用 Playwright 自带 Firefox：

```bash
npx --yes --package @playwright/cli playwright-cli install-browser firefox
```

真实浏览器验收依赖本机浏览器运行环境；TypeScript、Vitest 和 Pages 构建不能替代视觉与交互检查。
