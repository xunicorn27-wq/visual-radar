# 收藏与检索

## 查找创作参考

往期日报与我的收藏均支持关键词、内容分类、日报月份、视觉方法，以及“只看有原文证据”“只看精选”的组合筛选。筛选状态保存在网址中；进入日报再返回会保留筛选和阅读位置。

视觉方法（布光、构图、材质等）只使用已核验解读的结构化标签，不从标题关键词猜测。历史未核验条目仍可阅读；没有方法标签不代表没有参考价值。“有原文证据”表示证据可追溯，不代表编辑判断得到独立验证。

已核验条目的卡片显示一句“可以借鉴 · 编辑建议”；完整事实、建议与限制仍在日报的展开区域中。建议只是编辑给出的尝试方向，不是原作者已经完成的成果。

## 文章勘误与个人记录

打开收藏或往期页面时会读取最新公开索引，并更新已保存文章的标题、摘要、配图和方法等信息。不会改变个人备注、收藏状态、收藏时间或备注修改时间；发生变化会显示“文章信息已更新 · 个人备注保留”。较旧的索引或备份不会覆盖带较新修订时间的文章。

不能访问索引时仍显示本机收藏，并提供重试入口。索引暂时缺少某篇文章不会删除本机记录。收藏仍只在当前浏览器中保存，不会上传到服务器，也不自动跨设备同步。

## 两种导出

- **导出当前结果（含备注）**：Markdown 阅读版，只包含当前筛选结果，不能用于自动恢复。
- **备份全部收藏与备注**：JSON 完整备份，不受筛选影响；包括取消收藏后仍保留的备注，可在另一个浏览器或正式网站中导入。备份含个人备注，请妥善保管，不要提交到公开仓库。

## 从备份恢复

1. 选择 Visual Radar 导出的 JSON 文件（最大 5 MB）。
2. 查看新增、合并与备注冲突数量；有冲突时可展开比较原文。
3. 默认保留本机冲突备注。只有明确选择“用备份备注替换冲突备注”，并确认恢复，才会替换冲突文字。空白备注不会覆盖已有文字。
4. 点击“确认合并恢复”。重复记录按日报日期和文章 ID 合并；不清空本机库，不取消已有收藏。原有已收藏条目的收藏时间保留。

预览与取消不会写入数据。预览之后如果另一标签页修改了本机记录，恢复会被阻止，需重新预览。格式错误、版本不兼容或存储失败时不做部分恢复。建议在导入前先下载一份本机备份。

备注与存储仍受浏览器容量限制；本功能不是云端账户系统。清理网站数据前请先备份。
